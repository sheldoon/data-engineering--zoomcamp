# Data Engineering Zoomcamp — João Pedro Ferreira Resende

Repositório com anotações, códigos e exercícios do [Data Engineering Zoomcamp](https://github.com/DataTalksClub/data-engineering-zoomcamp) da DataTalks.Club.

Sou Engenheiro de Controle e Automação, com experiência em validação de dados e sistemas de qualidade em ambiente industrial. Este repositório documenta minha jornada de aprendizado em engenharia de dados, cobrindo desde containerização com Docker até data warehouses com BigQuery.
